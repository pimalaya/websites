# Bootstrap the websites monorepo with the Pimgate one-pager

Created the Pimalaya websites monorepo: an npm workspace where shared/ (`@pimalaya/shared`) carries the common layer extracted from the website and blog sources (letterpress design tokens and global styles, parameterized Nav and Footer, Button, Icon, Logo with an optional property tag, Container, and the reusable prerender script that strips the SPA module script and emits sitemap and robots), and each site is a package under sites/. The first site is the Pimgate one-pager at pimgate.pimalaya.org: hero, the provider deadline section (EWS retirement from 2026-10-01 phased through April 2027, SMTP AUTH basic default-off end of December 2026, basic auth already gone for hosted IMAP and SMTP), how the gateway works (neverest replica into a pimdir store, credential-less IMAP and SMTP frontends, durable sending), the open-source section, two offers (self-operated free, operated on your infra; prices are placeholders in sites/pimgate/src/lib/pricing.ts until the maintainer sets real numbers), and the five-bullet security posture. One flake.nix and shell.nix provide node for the whole workspace; the flake builds the Pimgate bundle reproducibly and the publish workflow deploys it to GitHub Pages. The website and blog repositories stay standalone for now and migrate in later.

Capabilities born: **workspace**, **pimgate-site**.
